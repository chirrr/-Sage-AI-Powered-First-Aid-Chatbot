# 🧠 Sage — AI-Powered First Aid Chatbot

An interactive **Streamlit-based First Aid & Health Assistant** that provides empathetic, conversational health guidance using the **Mistral LLM API**. Sage offers possible causes, immediate actions, lifestyle suggestions, and guidance on when to seek professional medical help.

> ⚠️ **Disclaimer:** This project is for educational/demo purposes only and is **not a substitute for professional medical advice**.

---

## 🚀 Features

* 💬 Chat-style health assistant UI (Streamlit)
* 🧠 Powered by Mistral LLM (`mistral-tiny`)
* ❤️ Empathetic, safety-first responses
* 🌟 Daily rotating health tips
* 🎨 Custom dark-themed UI with CSS
* 🛡️ Graceful fallback & error handling

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit** (Frontend & App framework)
* **Mistral API** (LLM)
* **Requests** (API calls)
* **JSON**

---

## 🔐 Environment Setup (IMPORTANT)

❌ **Do NOT hardcode API keys in GitHub**

Instead, use environment variables:

```bash
export MISTRAL_API_KEY="your_api_key_here"
```

Then update your code:

```python
import os
api_key = os.getenv("MISTRAL_API_KEY")
```

---

## ▶️ How to Run Locally

1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/sage-first-aid-chatbot.git
cd sage-first-aid-chatbot
```

2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

3️⃣ Run the app

```bash
streamlit run app.py
```
